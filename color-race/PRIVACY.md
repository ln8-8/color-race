# Privacy Policy — Color Race

_Last updated: November 24, 2026_

Color Race is a personal automation tool. It creates original animated race videos and uploads them to the
owner's own YouTube channel through the YouTube Data API.

## What data the app accesses
- The app signs in only with the channel owner's own Google account, using OAuth.
- It uses the YouTube Data API only to **upload videos and set thumbnails** on that one channel.
- It does **not** read, collect, store, sell or share any data about other users or viewers.

## Data storage
- The OAuth refresh token is stored only as an encrypted secret in the owner's private automation environment, which is GitHub Actions secrets.
- No personal data is sent to any third party.

## YouTube and Google
This app uses YouTube API Services. By using it, the channel owner is also bound by the
[YouTube Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).
Access can be revoked at any time at https://myaccount.google.com/permissions.

## Contact
Questions about this policy can be sent through the contact details on the Color Race YouTube channel's "About" page.
